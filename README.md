# To-Do List + AI Task Organizer (Django)

A simple, clean to-do list web app built with Django, plus a lightweight
"Generative AI" feature that organizes your tasks into a daily plan.

## Features
- Home page listing all tasks
- Add, edit, and delete tasks
- Priority (Low / Medium / High) and deadline per task
- Mark tasks as completed (one-click toggle)
- Search tasks by title/description
- Filter by priority and status (pending / completed)
- **AI Daily Plan** page: ranks your pending tasks by urgency (priority +
  deadline) and explains why, and suggests a priority automatically when
  adding a task if you don't pick one yourself

## Tech stack
- Python 3 + Django (backend, templates, ORM)
- SQLite (database — zero setup, file-based)
- Bootstrap 5 (via CDN, for clean styling — no build step needed)

## Setup

1. **Create and activate a virtual environment** (recommended):
   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run database migrations** (creates `db.sqlite3` with the Task table):
   ```bash
   python manage.py migrate
   ```

4. **(Optional) Create an admin user** to use the Django admin at `/admin/`:
   ```bash
   python manage.py createsuperuser
   ```

5. **Run the development server:**
   ```bash
   python manage.py runserver
   ```

6. Open your browser at **http://127.0.0.1:8000/**

## About the AI feature

The "AI Daily Plan" (`/ai-plan/`) and the automatic priority suggestion
when adding a task work **out of the box, with no API key or internet
connection needed** — they use a rule-based organizer
(`tasks/ai_organizer.py`) that scores tasks by priority and how close
their deadline is, then explains its ranking in plain language.

If you'd like it to use a real language model instead, set an
environment variable before running the server:

```bash
export OPENAI_API_KEY=sk-...        # Windows: set OPENAI_API_KEY=sk-...
pip install openai
```

With the key set, the daily plan is generated by calling OpenAI's chat
API; without it (or if the call fails for any reason, e.g. no internet),
the app automatically falls back to the built-in rule-based planner, so
the feature never breaks.
